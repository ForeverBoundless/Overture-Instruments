THE IDEA

A different kind of instrument company

Great sound should be a shared resource.

Instruments can change the way you think, play, and create. Access to them shouldn't depend on what you can afford.

Overture Instruments is an independent project building detailed, MIDI-playable emulators and creative tools for curious musicians everywhere. The software is free, the code is public, and the point is simple: make more music possible.

It's your instrument,
