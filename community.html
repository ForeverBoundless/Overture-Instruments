Browse OMNI instruments made by other users, audition them in your browser, and publish patches of your own.

Connect the community library

This prototype uses Supabase for accounts, patch records and optional audio previews. Add your Supabase project URL and publishable/anon key to js/shared/supabase-config.js, then apply the SQL migration at supabase/migrations/20261102000000_community_patches.sql in the Supabase SQL editor.

The browser key is public by design. The migration enables Row Level Security; never use a service-role key in frontend code.
